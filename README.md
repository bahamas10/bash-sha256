sha256 Implemented in Bash
=======================

Pure bash implementation of the sha256 checksum algorithm

Usage
----

```
./sha256 file.txt
./sha256 < file.bin
echo 'hello' | ./sha256
DEBUG=1 ./sha256 file.txt
```
